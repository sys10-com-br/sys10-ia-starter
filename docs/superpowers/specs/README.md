# Specs

O desenho de uma mudança antes do plano: o problema, as opções e a escolhida. A skill
`superpowers:brainstorming` grava aqui, depois de conversar com você.

- Arquivo: `AAAA-MM-DD-<assunto>-design.md`.
- É **registro datado**: não se edita depois. Mudou o desenho? Novo spec, que cita o antigo.
- Spec não é regra de negócio: a regra está em `docs/telas/`. O spec diz **como** construir.
