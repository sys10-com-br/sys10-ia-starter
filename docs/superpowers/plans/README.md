# Planos

O passo a passo para implementar um spec ou uma ficha: tarefas pequenas, com os arquivos, os testes e os
comandos de cada uma. A skill `superpowers:writing-plans` grava aqui; `superpowers:executing-plans` ou
`superpowers:subagent-driven-development` executa.

- Arquivo: `AAAA-MM-DD-<assunto>.md`.
- É **registro datado**: não se edita depois de executado. Plano novo para mudança nova.
- Use para tela ou mudança com mais de dois fluxos ou que toca várias camadas; mudança pequena dispensa plano.
