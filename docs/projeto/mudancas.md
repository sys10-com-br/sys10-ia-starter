# Mudanças

Toda mudança em algo que já estava aprovado em `docs/` ganha um `MU-NNN`, com a fonte. Assim ninguém
reimplementa a regra antiga achando que é a atual.

## Mudanças registradas

| ID | Data | O que mudou (antes → depois) | Fonte | Onde |
|---|---|---|---|---|
| MU-001 | <AAAA-MM-DD> | **Exemplo:** lista de pedidos abria com "Todos" → abre com "Pendentes" | ata DD/MM · D01 | `docs/telas/pedidos.md` |

## Descontinuado — não usar

Decisões mortas. Se o código ou um doc ainda usa uma delas, é bug.

| O que era | Por que morreu | Substituído por |
|---|---|---|
| <Exemplo: status "Em análise"> | <fundido com "Pendente"> | MU-001 |
